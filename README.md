# Temori

一个面向大学生小组的网页端协作产品。第一阶段聚焦课程小组作业：把组内沟通、任务分工、成果提交和审阅放在同一个群组中。竞赛团队和志愿活动是后续验证的场景。

## 想解决的问题

学生常在微信里组队做事，但任务、文件和反馈散落在聊天记录中。成员不容易看清谁负责什么、哪个成果是最新版、修改意见是否已经处理，以及任务是否真正完成。

## 核心流程

1. 用户通过邮箱一次性验证码注册或登录，创建群组，或按群号搜索并申请加入。
2. 群组成员在独立群聊中沟通；群主和组员都可以发布大任务，写明目标、解释、期限并附上参考文件。
3. 需要分工或讨论的大任务，由成员创建多个 Issue，明确负责人和截止时间；简单的大任务可以跳过 Issue。
4. 成员可针对一个或多个 Issue 提交成果，也可直接向大任务提交成果，附上文字、链接或文件；每次修改形成新版本。讨论型 Issue 可以记录结论后关闭。
5. 有 Issue 的任务由指定审阅人在成果版本下评论，选择「要求修改」或「通过」；修改后可再次提交，旧版本与反馈仍可追溯。
6. 大任务负责人汇总已通过的成果并提交最终版本；简单任务可直接提交最终成果。最终成果默认由群主验收，群主也可指定验收负责人；通过后记录必要的对外交付信息，再完成并归档。

独立群聊和完整的成果审阅都是首版必需能力。这里的“审阅”借鉴 GitHub 的协作流程，但成果不限于代码，也包括文档、PPT、图片、PDF、链接和志愿服务证明。
